# RMT Numerics

Numerical code and experiments for exploring **Random Matrix Theory (RMT)**, with a focus on large random matrices and their asymptotic behavior.

## Overview

This repository contains code for studying:

* Empirical eigenvalue distributions of large random matrices
* Growth rates and scaling behavior as matrix size increases
* Moment calculations and their large-size limits
* Permutation-based calculations arising in RMT
* The combinatorial and topological structures underlying moment expansions
* Numerical investigations of which surface topologies survive in the large-matrix limit

The goal is primarily to use numerical experiments to investigate and visualize the behavior predicted by random matrix theory.

## Repository Structure

The repository is organized around individual numerical experiments and projects. Each file or directory should include a short description of its purpose, the RMT problem it addresses, and any relevant mathematical background.

## Research Notes

Many of the computations in this repository are exploratory and are intended to support research, intuition, and numerical verification of theoretical results. Code may therefore change as ideas and experiments develop.
